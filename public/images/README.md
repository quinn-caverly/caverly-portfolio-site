# Project Images

Place your project images here!

## Image Requirements:

- **Recommended size**: 120x80px (or 240x160px for retina)
- **Format**: JPG or PNG
- **File naming**: lowercase with hyphens (e.g., `capital.jpg`)

## Current Mappings:

- `capital.jpg` → BlueCapital
- `lake.jpg` → BlueLakeOutpost
- `mountain.jpg` → BlueMountainOutpost
- `north.jpg` → BlueNorthOutpost
- `plains.jpg` → BluePlainsOutpost
- `red-capital.jpg` → RedCapital
- `edge.jpg` → RedEdgeOutpost
- `farm.jpg` → RedFarmOutpost
- `red-mountain.jpg` → RedMountainOutpost
- `red-north.jpg` → RedNorthOutpost

## Note:

If images are not found, placeholder images will be used instead.
You can update the mapping in `src/components/LocationMarker.tsx`
